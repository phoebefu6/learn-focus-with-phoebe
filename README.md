# Learn Focus with Phoebe

"Getting Focused": six 45-minute sessions on attention as a capacity you can protect and train.
Static HTML, no build step. Open `index.html`.

1. What attention is, and what it is not
2. When the mind leaves the task
3. Why focus fades over an hour
4. The attention bench
5. Designing the room and the phone
6. A focus block you can keep

Session 4's bench runs a go/no-go task in the style of the SART on the learner in the browser
(results stay in local storage) and a modelled pool of 200 synthetic participants
(`assets/fo-live.js`). `materials/fo_reference.py` reproduces the pool independently; run
`node materials/fo-node.js` and `python3 materials/fo_reference.py` and the outputs match.

The running case, Tomas, is constructed. Not medical advice.
